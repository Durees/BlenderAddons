# Material Connection Validator - Blender 插件

一个用于检测材质节点连接不正确的 Blender 插件。该插件可以帮助您发现材质节点图中的常见问题，如缺失连接、类型不匹配、循环依赖和未使用节点。

## 功能特性

- **自动检测**：一键扫描场景中所有材质的节点连接问题
- **多种检查类型**：
  - 缺失连接：检查重要输入插槽是否未连接
  - 类型不匹配：检查连接的数据类型是否兼容
  - 循环连接：检测节点之间的循环依赖
  - 未使用节点：找出未被任何输出使用的节点
- **可视化界面**：在 3D 视图侧边栏显示检测结果
- **快速定位**：点击问题项可直接在节点编辑器中选中对应节点
- **严重程度分级**：将问题分为警告、错误、严重三个等级
- **自动修复**：尝试自动修复一些常见问题

## 安装方法

### 方法一：通过 Blender 安装
1. 下载 `material_connection_validator.zip` 文件
2. 打开 Blender，进入 `编辑(Edit) > 偏好设置(Preferences) > 插件(Add-ons)`
3. 点击 `安装(Install)`，选择下载的 zip 文件
4. 在插件列表中搜索 "Material Connection Validator" 并启用

### 方法二：手动安装
1. 将插件文件夹复制到 Blender 的插件目录：
   - Windows: `C:\Users\[用户名]\AppData\Roaming\Blender Foundation\Blender\[版本]\scripts\addons\`
   - macOS: `/Users/[用户名]/Library/Application Support/Blender/[版本]/scripts/addons/`
   - Linux: `/home/[用户名]/.config/blender/[版本]/scripts/addons/`
2. 在 Blender 中启用插件

## 使用方法

### 基本使用
1. 打开 Blender，确保有一个包含材质的场景
2. 在 3D 视图的右侧面板中，找到 "Material Tools" 标签页
3. 点击 "验证所有材质" 按钮开始检测
4. 查看检测到的问题列表

#### 主面板

- **常见问题修复**：提供针对特定问题的快速修复按钮
- **批量修复**：一键修复所有常见问题

## 检测的问题类型

### 1. 缺失连接 (严重程度: 错误)
- **描述**：重要输入插槽（如 Base Color、Normal、Roughness 等）未连接
- **影响**：材质可能显示不正确或使用默认值
- **修复建议**：连接适当的节点或使用自动修复功能

### 2. 类型不匹配 (严重程度: 错误)
- **描述**：连接的两个插槽数据类型不兼容
- **示例**：将颜色节点连接到值输入
- **影响**：可能导致渲染错误或意外结果
- **修复建议**：使用转换节点或重新连接兼容的插槽

### 3. 循环连接 (严重程度: 严重)
- **描述**：节点之间形成循环依赖
- **影响**：可能导致无限循环、崩溃或不可预测的行为
- **修复建议**：断开循环连接，重新设计节点流程

### 4. 未使用节点 (严重程度: 警告)
- **描述**：节点未被任何输出使用
- **影响**：增加节点图复杂度，可能影响性能
- **修复建议**：删除未使用的节点或连接到输出

### 5. 未使用节点编辑器 (严重程度: 警告)
- **描述**：材质未启用节点编辑器
- **影响**：无法使用高级材质功能
- **修复建议**：启用节点编辑器或使用简单材质

## 使用示例

### 示例 1：检测缺失连接
1. 创建一个新材质并启用节点编辑器
2. 添加 Principled BSDF 节点但不连接 Base Color
3. 运行验证插件
4. 插件将报告 "缺失连接" 问题

### 示例 2：检测循环连接
1. 创建两个数学节点：Add 和 Subtract
2. 将 Add 的输出连接到 Subtract 的输入
3. 将 Subtract 的输出连接到 Add 的输入
4. 运行验证插件
5. 插件将报告 "循环连接" 问题

### 示例 3：检测未使用节点
1. 创建多个节点，但只连接部分到输出
2. 运行验证插件
3. 插件将列出所有未连接到输出的节点

要添加新的检测规则：
1. 在 `utils.py` 中实现检测函数
2. 在 `operators.py` 的 `validate_material` 方法中调用
3. 在 `MATERIAL_OT_validate_connections` 中添加对应的属性
4. 在面板中添加相应的 UI 控件

运行测试脚本：
```bash
blender --python test_material_validator.py
```

## 常见问题解答

### Q: 插件检测到问题但材质看起来正常？
A: 有些问题可能不影响最终渲染结果，但可能影响性能或可维护性。建议修复这些问题以确保材质图的正确性。

### Q: 自动修复功能安全吗？
A: 自动修复会尝试添加默认节点或断开问题连接。建议在使用前备份材质，或手动检查修复结果。

### Q: 插件会影响渲染性能吗？
A: 插件只在用户主动运行时执行检测，不会影响正常渲染性能。

### Q: 支持自定义节点组吗？
A: 是的，插件会检查自定义节点组的内部连接，但不会深入检查节点组内部的复杂逻辑。

### Q: 如何报告错误或请求功能？
A: 请通过 GitHub Issues 页面提交问题报告或功能请求。
