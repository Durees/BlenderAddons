# 角度限制参数说明

## 问题：3782和66的关系

用户注意到原始代码中有`3.141592653589793`这个值，并询问它与66的关系。

## 解释

### 1. 角度与弧度的转换

在3D图形和数学中，角度有两种表示方式：
- **角度（Degrees）**：日常使用的单位，一个圆360°
- **弧度（Radians）**：数学计算使用的单位，一个圆2π弧度

转换公式：
```
弧度 = 角度 × π / 180
角度 = 弧度 × 180 / π
```

其中π（圆周率）≈ 3.141592653589793

### 2. 原始代码中的实现

在`blender_script_template.py`第113行：
```python
angle_limit=uv_angle_limit * 3.141592653589793 / 180.0,  # 角度转弧度
```

这里：
- `uv_angle_limit` = 66.0（角度）
- `3.141592653589793` = π的近似值
- 计算：66 × 3.141592653589793 ÷ 180 ≈ 1.1519弧度

### 3. Blender API要求

Blender的`bpy.ops.uv.smart_project()`函数的`angle_limit`参数**需要以弧度为单位**，但用户通常以角度为单位思考。

### 4. 插件中的改进

在我的插件实现中，使用了更简洁的方式：

```python
from math import radians
# ...
angle_limit=radians(settings.angle_limit)
```

`radians()`函数是Python标准库函数，内部执行相同的计算：
```python
def radians(degrees):
    return degrees * 3.141592653589793 / 180.0
```

## 具体数值关系

对于默认值66°：
- 66 × π / 180 = 66 × 3.141592653589793 / 180
- = 207.34511513692634 / 180
- ≈ 1.1519173063162574弧度

## 为什么使用66°？

66°是Blender智能UV投影的常用默认值，因为：
1. 它能在保持UV岛屿连续性和避免过度分割之间取得平衡
2. 对于大多数几何形状都能产生良好的结果
3. 是Blender官方推荐的起始值

## 插件中的角度参数

在插件UI中，用户看到的是**角度值**（66°），但插件内部自动转换为弧度：
- 用户输入：66（度）
- 插件转换：`radians(66)` ≈ 1.1519（弧度）
- 传递给Blender：1.1519弧度

## 总结

- **66**：角度值，用户友好的输入
- **3.141592653589793**：π的近似值，用于角度到弧度的转换
- **关系**：66° = 66 × π / 180 ≈ 1.1519弧度
- **插件处理**：自动转换，用户只需输入角度值

这样设计使得插件更易用，用户不需要理解弧度制的细节。
